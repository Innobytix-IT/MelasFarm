# 🌾 MelasFarm

Ein 3D-isometrisches Farming-Spiel im Browser — als Geschenk gebaut.

## 🎮 Spielen

**Direkt im Browser:** [innobytix-it.github.io/MelasFarm](https://innobytix-it.github.io/MelasFarm/)

**Oder herunterladen** (offline spielbar):
1. Bei [`MelasFarm.html`](MelasFarm.html) auf **"Download raw file"** klicken
2. Datei doppelklicken — läuft in jedem modernen Browser

Beide Varianten speichern automatisch in `localStorage`. Die heruntergeladene Version prüft einmal am Tag auf Updates und bietet einen Download an.

## ✨ Features

- 🌱 **11 Feldfrüchte** — Weizen, Karotten, Tomaten, Erdbeeren, Kürbis, Ananas, Melone, Kirsche u.v.m.
- 🏠 **30+ Gebäude, Bäume, Dekorationen** — Bauernhaus, Landhaus, Schloss, Bäume, Brunnen, Windmühle
- 🐄 **11 Tiere mit passivem Einkommen** — Kuh, Pferd, Schaf, Huhn, Bienen, u.v.m.
- 🗺️ **Erweiterbare Farm** — von 16×16 bis 30×30 Kacheln (Land kaufen im Markt)
- 🌸 **4 Jahreszeiten** — Frühling, Sommer, Herbst, Winter mit unterschiedlichen Boni
- 📋 **Tägliche Quests** — verdiene Extra-Münzen
- 🖱️ **RTS-Kamera** — Drag zum Verschieben, Mausrad zum Zoomen, Pfeiltasten zum Panning

## ⌨️ Steuerung

| Taste | Aktion |
|-------|--------|
| **Maus ziehen** | Karte verschieben |
| **Mausrad** | Rein-/Rauszoomen |
| **Pfeiltasten** | Karte verschieben |
| **H** | Kamera zurücksetzen |
| **P** | Pflügen |
| **W** | Gießen |
| **M** | Markt öffnen |
| **X** | Verkaufen / Abreißen |
| **ESC** | Multi-Tool (Ernten) |

## 🔄 Version

Aktuell: **v1.0.0**

Die heruntergeladene Version prüft täglich, ob es eine neuere gibt, und bietet den Download an. Speichere die Datei einfach am selben Ort — deine Spielstände bleiben.

## 🛠️ Technik

Alles in einer einzigen HTML-Datei — reines HTML/CSS/JavaScript, keine Frameworks, keine Build-Tools. Die 3D-Isometrik läuft über CSS-Transforms mit `preserve-3d`.
